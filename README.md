# copy-on-select — an Agents Hub plugin

> Original author: [@tolaysha](https://github.com/tolaysha) · upstream: [tolaysha/hub-plugin-copy-on-select](https://github.com/tolaysha/hub-plugin-copy-on-select). This is the copy the Hub catalog installs; the author's updates are taken into it from upstream.
>
> License: Apache-2.0 (Icons8 LLC)

Select text in the feed with the mouse and it is already on the clipboard: no Cmd/Ctrl+C needed. Like in a terminal: faster than reaching for Cmd+C.

## Install

In Agents Hub: "Settings" → "Plugins" → "Find" → `copy-on-select`.
